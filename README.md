### ★⋆˙ CORE // ARCHIVE RULE

Historical material stays where it was preserved. The seven-room layer explains the archive; it does not reinterpret old files as current implementation.

---

This repository preserves development material created before the
Post-Apollo / Metapollo projects were moved to normal Git-based development.

## Important

This is a HISTORICAL ARCHIVE.

Files in this repository are not necessarily current, stable, complete,
or intended to replace the authoritative project repositories.

Current development lives in repositories such as:

- The-Post-Apollo-Project
- Post-Apollo-Pretty-Kitty
- Post-Apollo-SwayPx
- other Post-Apollo repositories as they are migrated

## Contents

### RiceCodeHistory/

Historical generated/downloaded source and project documentation.

Includes development history for:

- Taskbars / Quickshell
- AppControl
- Messaging
- Notifications
- edge-reveal experiments
- ReceiverDeck
- Post-Apollo / Metapollo design documents

### CRT-packages/

Original downloaded CRT development packages preserved as downloaded.

### CRT-snapshots/

Extracted copies of the CRT packages so historical shader source can be
searched and compared through GitHub.

### ReceiverDeck-history/

Historical ReceiverDeck revisions recovered from the downloads archive.

### TV-history/

Historical Post-Apollo TV helper material.

### MANIFEST.csv

Machine-generated archive index containing:

- path
- project family
- size
- SHA-256
- modification timestamp

## Preservation Policy

The original Downloads archive remains untouched.

This repository is a curated/searchable preservation copy.

Historical timestamps and original package files are retained where possible.

Do not treat modification dates or filenames alone as proof of exact
development ordering. They are historical evidence, not reconstructed Git
commit history.
